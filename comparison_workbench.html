🧪 Hands-On Testing Scenarios

How to Test MazAPI Features on Your Own Applications & Websites

Step-by-step interactive scenarios demonstrating how developers and AppSec engineers use MazAPI features on local, staging, or production websites and APIs.

🌐
Browser Extension

1. Test Chrome Side Panel on Any Website

Intercept live traffic, inspect JWT claims for weak secrets, and replay tampered BOLA requests on any web application in real-time.

Step 1
Open Chrome/Brave & navigate to your target site (e.g. http://localhost:3000 or jwt.io).
Step 2
Click MazAPI Extension icon to open the BOLT Side Panel.
Step 3
Log in to harvest Bearer tokens; check JWT Inspector for alg:none & expiration warnings.
Step 4
Use Request Manipulator to edit parameters (BOLA/IDOR) & click Replay Request.
Side Panel Shortcut: Ctrl+Shift+Y (Windows) / Cmd+Shift+Y (Mac)
⚡
AST Surface Engine

2. Scan Your Own Source Code AST

Map API endpoints, shadow routes, and parameters across 7 ecosystems (Python, Node, Java, .NET, Go, PHP, C/C++) before deployment.

Step 1
Open terminal in your project directory.
Step 2
Run static AST route discovery:
python cli.py app-surface scan /path/to/your/codebase --format table
Step 3
Check PR diffs for undocumented shadow routes:
python cli.py app-surface diff --base main --head feature-branch /path/to/repo
🤖
AI Agent Audit

3. Audit Your AI Agents & Generate AI-BOM

Evaluate LangChain, CrewAI, AutoGen, or Bedrock tools for confused deputy, excessive agency, and physical actuation risks.

Step 1
Scan AI Agent source files against EU AI Act & NIST AI RMF:
python cli.py agent-audit scan /path/to/ai/agent/code --governance
Step 2
Export CycloneDX 1.6 AI-BOM for AI models & tool sinks:
python cli.py agent-audit scan /path/to/code --format ai-bom -o ./ai-bom.json
🎯
Active DAST Scanner

4. Run Active DAST Scans Against Your API

Execute zero-egress dynamic security probes (OWASP API Top 10) against your live staging or production API endpoints.

Step 1
Target your API with Bearer JWT or API Key auth:
python cli.py scan --target https://api.yourcompany.com --auth "Bearer YOUR_JWT"
Step 2
Export SARIF report for GitHub Code Scanning:
python cli.py scan --target https://api.yourcompany.com --format sarif -o results.sarif
📡
IoT & Edge Security

5. Test Embedded IoT Devices & Firmware

Parse embedded C/C++ firmware (ESP-IDF, Arduino) & audit MQTT topic wildcards, CoAP reflection, and unsigned OTA uploads.

Step 1
Scan embedded microcontroller C/C++ source code:
python cli.py app-surface scan /path/to/embedded/firmware/src
Step 2
Run dynamic IoT vulnerability audit on device IP:
python cli.py iot-audit --target http://192.168.1.100 --broker mqtt://192.168.1.100:1883
🛡️
ML Anomaly Proxy

6. Monitor Live Microservice Traffic & Anomaly ML

Proxy backend traffic through MazAPI's 32-feature Random Forest & Isolation Forest ML model for real-time zero-day blocking.

Step 1
Point frontend requests through local proxy (http://localhost:9000).
Step 2
Set upstream target header: X-Target: https://api.yourcompany.com.
Step 3
Watch live threat scores & anomaly badges at http://localhost:9000/dashboard.
Dashboard URL: http://localhost:9000/dashboard
