# Contributing to MazAPI Security Platform

Thank you for your interest in contributing to **MazAPI**!

## Development & Test Guidelines
- **Python**: Follow PEP 8 guidelines. Ensure type hints and docstrings are provided.
- **Testing**: Run the full test suite before submitting PRs:
  ```bash
  python run_all_tests.py
  ```
- **CLI Commands**: Verify CLI options using `python cli_entry.py --help`.
