📖 How to Use MazAPI BOLT
1
Auto-Discovery & Traffic Capture
MazAPI silently monitors network activity in this tab. As you browse, it normalizes parameter templates (e.g. /users/42 → /users/{id}) and detects API documentation endpoints.
How to try: Navigate to your web app or API test target (e.g. http://localhost:8000/ui). Switch to the Capture tab to watch routes appear automatically.
2
Auth Harvesting & JWT Inspection
Harvests Authorization Bearer tokens, API keys, and cookies from headers and client-side JavaScript. Automatically parses JWTs to flag alg:none bypasses, symmetric HS256 keys, and expired credentials.
How to try: Log into an account on your target web app. Open the Auth tab to view decoded JWT headers, payload claims, and expiration timers.
3
Request Manipulator & Replay (BOLA / IDOR)
Craft and tamper with API requests directly in the sidebar. Use the Smart Parameter Picker to swap observed user IDs, test cross-tenant object access (BOLA), and test privilege escalation.
How to try: Open the Replay tab, select an observed ID or admin payload (user_id=2, role=admin), and click Send Replay Request to test authorization enforcement.
4
Selective OpenAPI 3.0 Export
Extract live browser traffic into standardized OpenAPI 3.0 specifications. Filter specific endpoints or export the entire discovered surface.
How to try: Open the OAS tab, check the endpoints you want, and click Download YAML or Download JSON.
5
Correlated Threat Chains & Scorecard
Combines active scan results, behavioral telemetry, and exposed keys to correlate multi-step attack paths (e.g. Mass Assignment + Weak JWT = Full Account Takeover).
How to try: After running a scan, visit the Threats tab to see your letter grade, threat counts, attack surface map, and correlated exploit chains.
6
Active OWASP API Top 10 Scanner
Runs 12+ client-side active vulnerability tests: Broken Object Level Authorization, Rate Limiting, JWT forgery, Path Traversal, SSRF, CORS wildcard, GraphQL Introspection, and PII leaks.
How to try: Open the Scan tab, verify your target URL, click Run Full Scan, and explore findings in the Results tab with full request/response evidence and PCI-DSS / GDPR compliance mappings.
