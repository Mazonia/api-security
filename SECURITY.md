# Security Policy

## Reporting Security Vulnerabilities

As a security intelligence platform, maintaining strict security and responsible disclosure is essential.

If you identify a vulnerability within MazAPI or any of its sub-engines:
1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately with steps to reproduce and proof-of-concept.
3. The maintainers will respond within 24 hours to confirm receipt and coordinate a security release.
